# 펫 파일 형식 (pet.json, version 1)

샤네루 데스크톱 앱(맥 `Chanelu.app`, 윈도우 `Chanelu.exe`)은 기본 샤네루 대신 다른 펫을 띄울 수 있어요.
펫 하나는 **pet.json + 스프라이트 시트 이미지** 두 파일이에요.

## 펫 파일 (.chanelupet)

사용자에게 줄 때는 두 파일을 **zip으로 묶고 확장자를 `.chanelupet`으로** 해요 (예: `흰 강아지.chanelupet`).
`pet.json`은 zip의 맨 위나 폴더 하나 안에 두면 돼요. 파일 100개 미만, 폴더 밖을 가리키는 경로(`..`, `/`로 시작)는 거절해요.

```text
흰 강아지.chanelupet  (zip)
├── pet.json
└── spritesheet.png
```

펫 파일을 더블클릭하면 앱이 열려(이미 떠 있으면 그 앱이 받아서) 펫 목록에 넣고 그 펫으로 바꿔요.
그래서 웹 제작기의 다운로드는 이렇게 하면 돼요.

- **처음 받는 사람**: `Chanelu.app`(또는 `Chanelu.exe`) + `.chanelupet`을 묶은 zip.
  앱을 처음 실행하면 응용 프로그램 폴더로 옮길지(윈도우는 설치할지) 물어봐요.
  한 군데에 설치돼 있어야 펫 파일을 더블클릭했을 때 늘 같은 앱이 열려요.
- **이미 앱이 있는 사람**: `.chanelupet`만.

앱 옆에 `PetData/pet.json`을 두는 방식도 여전히 동작해요 (테스트용).

```text
MyPet/
├── Chanelu.app  (또는 Chanelu.exe)
└── PetData/
    ├── pet.json
    └── spritesheet.png
```

## 권장 시트 구성 (새 펫의 기본 틀)

웹 제작기에서 만드는 펫은 **4열 × 6행**을 기본으로 해요. 행마다 동작 하나, 칸은 모두 같은 크기예요.
기본 샤네루(8열 × 11행)는 이 틀과 상관없이 지금 그대로예요.

| 행 | 동작 | pet.json 이름 | 프레임 번호 |
|---|---|---|---|
| 1 | 정면으로 서서 눈 깜빡이기 | `idle` | 0–3 |
| 2 | 오른쪽을 보고 걷기 | `walk` (`walkFacing: "right"`) | 4–7 |
| 3 | 엎드려 잠들기 | `sleepStart` (8–11) → `sleep` (11, 10 반복) | 8–11 |
| 4 | 제자리 점프 | `jump` | 12–15 |
| 5 | 정면을 보고 고개를 갸우뚱 (한쪽으로만 그려요. 앱이 반은 좌우로 뒤집어 양쪽으로 기울여요) | `look` | 16–19 |
| 6 | 입을 벌리고 웃기 | `happy` | 20–23 |

8프레임(8열 × 6행)으로 만들 수도 있어요. 행 순서는 같고, 프레임 번호는 행 × 8부터예요.
속도(`fps`)는 4프레임 기준 값에 프레임 수 / 4를 곱해요 (8프레임이면 두 배). `sleep`은 마지막 두 칸을 거꾸로 반복해요.

```json
{
  "version": 1,
  "name": "쵸콘이",
  "sprite": "spritesheet.png",
  "frameWidth": 313,
  "frameHeight": 313,
  "columns": 4,
  "walkFacing": "right",
  "animations": {
    "idle":       { "frames": [0, 1, 2, 3], "fps": 4 },
    "walk":       { "frames": [4, 5, 6, 7], "fps": 7 },
    "sleepStart": { "frames": [8, 9, 10, 11], "fps": 3 },
    "sleep":      { "frames": [11, 10], "fps": 1 },
    "jump":       { "frames": [12, 13, 14, 15], "fps": 5 },
    "look":       { "frames": [16, 17, 18, 19], "fps": 4 },
    "happy":      { "frames": [20, 21, 22, 23], "fps": 5 }
  }
}
```

## 예시

```json
{
  "version": 1,
  "name": "우리 콩이",
  "sprite": "spritesheet.png",
  "frameWidth": 192,
  "frameHeight": 208,
  "walkFacing": "right",
  "animations": {
    "idle":  { "frames": [0, 1, 2, 3], "fps": 4 },
    "walk":  { "frames": [8, 9, 10, 11], "fps": 8 },
    "sleep": { "frames": [16, 17, 18], "fps": 3 },
    "jump":  { "frames": [24, 25, 26, 27], "fps": 10 },
    "react": { "frames": [32, 33, 34], "fps": 8 }
  }
}
```

## 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| `version` | | `1`. 앱이 아는 버전보다 크면 "앱을 업데이트해 주세요"라고 알려요. |
| `name` | | 메뉴와 툴팁에 보이는 이름. 없으면 "쵸콘이". 웹 제작기에서 만들 때 정해요. |
| `sprite` | ✓ | 시트 이미지 파일 이름 (PNG 권장, 투명 배경). pet.json과 같은 폴더 기준이고, `..`나 절대 경로는 쓸 수 없어요. |
| `frameWidth`, `frameHeight` | ✓ | 프레임 한 칸의 픽셀 크기 (1–4096). |
| `columns` | | 한 줄에 프레임이 몇 칸인지. 없으면 `이미지 너비 / frameWidth`. |
| `walkFacing` | | `walk` 프레임이 바라보는 방향, `"right"`(기본) 또는 `"left"`. 반대 방향은 좌우를 뒤집어 그려요. |
| `animations` | | 동작 이름 → `{ "frames": [...], "fps": 숫자 }`. 아래 표 참고. |

**프레임 번호**는 시트를 왼쪽 위부터 오른쪽으로, 줄이 끝나면 다음 줄로 세요: `번호 = 행 × columns + 열` (0부터).
시트 밖을 가리키는 번호는 무시해요.

시트는 **칸이 고르게 나뉜 격자**여야 해요. 프레임마다 위치나 크기를 따로 맞추는 기능은 없으니,
웹 제작기에서 프레임을 정리한 다음 고른 격자로 다시 그려서 내보내야 해요.

동작마다 `fps`(초당 프레임, 최대 60)를 쓸 수 있고, 없으면 동작별 기본 속도를 써요.
반복 여부는 동작마다 정해져 있어서 `loop` 값은 읽지 않아요 (적어 둬도 괜찮아요).
`"flip": true`를 넣으면 그 동작을 좌우로 뒤집어 그려요.

## 동작

모든 동작은 선택이에요. 없는 동작은 오른쪽 열의 다른 동작으로 대신해요.

| 이름 | 언제 | 반복 | 기본 속도 | 없으면 |
|---|---|---|---|---|
| `idle` | 가만히 있을 때 | 반복 | 6.25 fps | 아무 동작의 첫 프레임 하나 |
| `look`, `happy`, `sit`, `sitBlink` | 가만히 있을 때 가끔 섞여요 | 반복 | 6.25 fps | `idle`만 |
| `walk` | 화면 아래를 걸을 때 (`walkFacing` 방향) | 반복 | 10 fps | 걷지 않고 제자리 |
| `walkRight`, `walkLeft` | 방향별로 따로 그린 걷기 (`walk`보다 우선) | 반복 | 10 fps | `walk`를 뒤집어서 |
| `jump` | 들었다 놓았을 때, 저장했을 때 | 한 번 | 9 fps | `react` → `happy` → `idle` |
| `react` | 클릭했을 때 (`jump`, `wave`, `beg`, `happy`와 섞여서 무작위) | 한 번 | 9 fps | `jump` 등 |
| `wave`, `beg` | 클릭 반응. VS Code에서 AI가 확인을 기다릴 때 (`wave` → `beg`) | 한 번 | 9 fps | `react` / `jump` |
| `drag` | 마우스로 들고 있을 때 | 반복 | 8.3 fps | `react` → `jump` → `idle` |
| `sleepStart` | 잠드는 중 (눕기) | 한 번 | 4.5 fps | 바로 `sleep` |
| `sleep` | 자는 중 | 반복 | 2.2 fps | `idle` |
| `wake` | 깨어날 때 | 한 번 | 6.7 fps | `sleepStart`를 거꾸로, 그것도 없으면 바로 깸 |

## 펫 목록과 펫 바꾸기

앱은 펫 목록을 갖고 있어요. 메뉴(맥은 메뉴 막대, 윈도우는 트레이) → **펫 바꾸기**에서
**꽃개 샤네루**와 목록의 펫 중 하나를 고르면 바로 바뀌고, 다음에 켤 때도 그 펫이 나와요.
지금 펫이 아닌 펫은 **펫 바꾸기 → 목록에서 지우기**로 뺄 수 있어요.

**새 펫이 목록에 들어가는 방법**: 펫 파일(`.chanelupet`)을 더블클릭하거나, 옆에 `PetData`가 있는 앱을 실행하면 돼요.
펫이 목록에 복사되고 그 펫으로 바뀌어요. 그 뒤로는 받은 파일을 지워도 목록에 남아요.
이미 목록에 있는 펫(내용까지 똑같은 펫)의 앱을 다시 실행하면 바꾸지 않고, 마지막으로 고른 펫을 그대로 띄워요.

**이름이 같은 펫**이 이미 목록에 있으면 물어봐요.
- **바꾸기**: 예전 펫을 지우고 새 펫으로 (웹사이트에서 고쳐서 다시 받았을 때)
- **따로 추가하기**: 둘 다 남겨요. 메뉴에는 두 번째부터 "이름 (2)"처럼 보여요.
- **취소**: 목록에 넣지 않고 마지막으로 고른 펫을 띄워요.

목록 위치 (펫마다 `<id>/pet.json` + 시트, id는 파일 내용으로 만든 값이라 같은 펫은 한 번만 들어가요)
- 맥: `~/Library/Application Support/Chanelu/Pets/`
- 윈도우: `%APPDATA%\Chanelu\Pets\`

## 앱이 펫을 찾는 순서

**맥 (Chanelu.app 혼자 실행)**
1. 환경 변수 `CHANELU_PET` (pet.json 또는 그 폴더 경로, 테스트용, 목록에 넣지 않아요)
2. 앱 옆의 `PetData/pet.json`, 없으면 `pet.json` — 목록에 없던 펫이면 넣고 그 펫으로
   (`.chanelupet` 파일은 실행 중에 언제든 열 수 있어요)
   (인터넷에서 받은 앱을 macOS가 임시 위치로 옮겨 실행해도 원래 위치를 찾아요)
3. 펫 바꾸기에서 마지막으로 고른 펫
4. 기본 샤네루

**윈도우 (Chanelu.exe)**
1. 실행 인자(`.chanelupet` 또는 pet.json 경로. 파일을 exe에 끌어다 놓아도 돼요), 없으면 exe 옆의 `PetData\pet.json`, `pet.json`
   — 목록에 없던 펫이면 넣고 그 펫으로
2. 펫 바꾸기에서 마지막으로 고른 펫
3. 기본 샤네루

펫 파일을 읽지 못하면 그 이유를 창으로 알려 주고 다음 순서로 넘어가요.

**VS Code 확장**은 지금처럼 샤네루 시트를 넘겨요. 첫 인자로 `.json` 경로를 주면 그 펫을 띄워요.

## 설치 위치

- 맥: 처음 실행할 때 `/Applications/Chanelu.app`으로 옮길지 물어봐요. 예전 버전이 있으면 휴지통으로 보내고 바꿔요.
  "이대로 쓰기"를 고르면 다시 묻지 않아요.
- 윈도우: 처음 실행할 때 `%LOCALAPPDATA%\Programs\Chanelu\Chanelu.exe`로 설치할지 물어봐요
  (관리자 권한 필요 없음). 시작 메뉴에 "꽃개 샤네루" 바로 가기를 만들고,
  `.chanelupet` 파일 연결은 실행할 때마다 지금 실행한 exe로 맞춰요.
